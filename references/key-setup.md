# 申请高德 API Key

## 必须选「Web服务」，不是「Web端(JS API)」

这是本项目最常见的失败原因。选错类型会得到 `infocode=10009`
（`key 与平台不匹配`），而错误信息不会告诉你「你选错了」。

---

## 步骤

1. 打开 <https://lbs.amap.com/>，注册并登录（需实名认证）。
2. 右上角「控制台」→ 左侧「应用管理」→「我的应用」→「创建新应用」。
   - 应用名称随意，例如 `poi-collector`。
   - 应用类型选「出行」或「其他」都可以。
3. 在该应用下点「添加 Key」：
   - **Key 名称**：随意。
   - **服务平台**：⚠️ **必须选「Web服务」**。
   - **IP 白名单**：本地跑可以留空；部署到服务器建议填服务器出口 IP。
4. 复制生成的 32 位十六进制字符串。

> 服务平台选错（例如「Web端(JS API)」）→ 请求返回 `10009`。
> 解决办法只有一个：删掉重建，选「Web服务」。

## 配置到本项目

三种方式，优先级从高到低：

### 1. 环境变量（推荐给 CI / 临时使用）

```powershell
$env:AMAP_KEY = "你的32位key"
```

```bash
export AMAP_KEY="你的32位key"
```

### 2. 本地 config.json（推荐给日常使用）

复制 `config.example.json` 为 `config.json`，填入 key：

```json
{
  "key": "你的32位key"
}
```

`config.json` 已在 `.gitignore` 里，**不会**被提交。
仓库里只有 `config.example.json`（占位符）。

### 3. 交互式粘贴

既没有环境变量也没有 `config.json` 时，CLI 会在终端提示粘贴。
但 Agent 调用场景必须用前两种——Agent 环境没有可交互终端。

## 配额与计费

- 个人开发者有每日免费额度（具体数值以控制台「配额管理」为准，会变）。
- `v3/place/text` 每次请求算 1 次调用。
- 一次典型采集（1 关键词 × 1 城市）约 **10 次请求**。
- 4 个查询单元约 36 次请求。
- 超限返回 `10003`（日配额）或 `10044`（账号维度），本项目会立即中止并告知次日恢复。

**估算公式**：`关键词数 × 地区数 × 10`。跑大批量前先算一遍。

---

## 安全

- 不要把 key 提交到 Git、贴到 issue、写进截图。
- 不要把 key 硬编码进脚本。
- 如果 key 泄露，在控制台删除并重建。
- 不要共用他人的 key——配额、IP 白名单、封禁风险都算在 key 所有者头上。
